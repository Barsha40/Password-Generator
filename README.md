
# Password Generator

## Description
A Python-based password generator that creates
random passwords using selected character types.

## Features
- Generate random passwords
- Select password length
- Include lowercase letters
- Include uppercase letters
- Include numbers
- Include special symbols
- Ensures at least one character from each selected type
- Uses Python secrets module for secure generation

## Technologies Used
- Python
- Secrets Module
- String Module

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

   python password_generator.py

4. Enter the desired password length.
5. Select your preferred character types.
